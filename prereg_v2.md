## 0. Changelog v1 -> v2 (both approved by Steve, 2026-11-12 3:32 PM ET)
**Fix 1 – noise rescale.** v1 rescaled Δχ² by s² = max(1, χ²_M0/(N−5)). χ²_M0 contains the companion signal itself, so a real signal inflated s² and suppressed its own significance (offline tests of the v1 fitter: injected 9.4 MJup companion detected in only 60–68% of runs vs ~98% for the unrescaled statistic; null behaviour fine). v2 uses s²_W = max(1, χ²_Mc(W)/(N−7)), the reduced χ² of the fit that INCLUDES the window's orbit term. Why this option rather than a control-derived rescale: (i) it is star-specific, so it adapts to Tabby's own error underestimation (e.g. residual neighbour or calibration effects) whereas a control-derived factor assumes Tabby's error budget equals the controls' average; (ii) it needs no extra assumption and uses exactly the same statistic for Tabby and for controls, so the control null distribution (Section 4 G3) calibrates it directly; (iii) its known cost, a slight bias toward smaller s² because the orbit term is fitted (2 dof, handled by N−7), is exactly what the control-calibrated threshold in Fix 2 guards against. A control-derived rescale would only fix signal absorption by ignoring Tabby-specific noise.
**Fix 2 – gate G3.** v1 said a control false-positive rate (FPR) above 1.5% raises the threshold but also made the result INCONCLUSIVE, so the raise could never be used. v2: FPR above 1.5% for a window raises that window's threshold T_W to the controls' 99th percentile of S_W (never below 13.82) and does not make the result inconclusive; G3 now fails only if fewer than 200 valid controls are available.

## 1. Claim under test
arXiv:2607.20643: a ~9.4 +4.9/−4.1 MJup companion to KIC 8462852 (Gaia source_id 2081900940499099136; DR3 ϖ = 2.2545 mas), K = 162 +76/−69 m/s, one of five period windows (W1 1029.7–1031.5, W2 1034.5–1035.3, W3 1301.0–1303.6, W4 1345.648±0.008, W5 1367.3–1368.3 d), transit anchor BJD 2458730.164. Nominal astrometric amplitudes α_nom (K=162, e=0.09, ϖ=2.2545 mas): 34.5, 34.6, 43.5, 45.0, 45.7 µas (W1–W5). See memo/paper_extract.md.

## 3. Processing (frozen)
Use only CCD samples with used_by_agis_al=True; weight 1/(centroid_pos_error_al²+agis_source_excess_noise²); collapse the CCD samples of each FoV transit to one weighted abscissa (time = weighted mean of obs_time_tcb + obs_time_bary_corr; scan angle and parallax_factor_al from the table). Model: w = dα*·sinψ + dδ·cosψ + ϖ·pf + (μα* sinψ + μδ cosψ)·t + orbit. M0 = 5 parameters. Mc(W) = M0 + orbit term (cx sinψ + cy cosψ)·X′_W(t), where X′_W is the unit edge-on stellar reflex template for P = window centre, e=0.09, ω_s=141°, phase anchored to transit BJD 2458730.164 with ω_p=ω_s+π (opposite convention reported as a sensitivity). Rescaling (v2): per window s²_W = max(1, χ²_Mc(W)/(N−7)), the reduced χ² of the fit including that window's orbit term (the opposite-phase variant uses its own χ²_Mc). Statistic S_W = (χ²_M0 − χ²_Mc)/s²_W; amplitude a_W = hypot(cx,cy). Upper limits use the covariance scaled by s²_W. Tabby and every control use the identical statistic. (χ²_M0/(N−5) is reported as a diagnostic only.)

## 4. Calibration gates (G1, G2, G4 and the control-count part of G3 must pass, else the outcome is INCONCLUSIVE (data quality) and the cause is reported)
G1 Tabby has epoch astrometry with ≥60 FoV transits and DR4 RUWE<1.4. G2 The 5-parameter fit reproduces the catalogue parallax within 3σ. G3 (v2) At least 200 valid controls (those whose fits succeed) are available. Over the controls, the fraction with S_W above 13.82 (χ²₂, p=0.001) is computed per window (expected 0.1%); if it exceeds 1.5%, that window's detection threshold T_W is raised to the controls' 99th percentile of S_W (never below 13.82). A raised threshold does NOT make the result inconclusive; only fewer than 200 valid controls fails G3. G4 Tabby's ipd_frac_multi_peak and ipd_gof_harmonic_amplitude ≤ the 95th percentile of the controls (blend/neighbour-contamination screen). Phase A sims: a scan-angle-windowed leak needs ≥10% of the G=17.6 neighbour's flux inside Tabby's windows to fake a detection; static offsets are absorbed.

## 5. Decision rule (applied per window, then overall)
DETECT(W): S_W ≥ max(T_W, 19.1) [T_W = 13.82 unless raised by the G3 control calibration; 19.1 = ΔBIC≥10 for N≈93] AND 0.4 ≤ a_W/α_nom(W) ≤ 2.0 AND the same-window fit with the opposite-phase template does not give S larger by more than 4 (phase consistency). Overall DETECTED if any window satisfies DETECT; windows ranked by S; DR4 NSS orbit/acceleration rows for Tabby (period within ±5% of any window) are reported as supporting evidence only.
EXCLUDE(W): not DETECT(W) and the 95% credible upper limit on amplitude (flat prior on a ≥ 0, uniform orientation, Gaussian likelihood in (cx,cy), other parameters profiled) converts to a mass limit M95(W) < 5.3 MJup (= 9.4 − 4.1, the paper's 1σ lower bound; conversion K→M uses M*=1.19 Msun, e=0.09, sin i=1). WEAK-EXCLUDE(W): M95(W) < 9.4 MJup (rules out the face-value claim but not its low-mass tail).
Overall: CLAIM SUPPORTED if DETECTED; CLAIM EXCLUDED (strong) if all five windows are EXCLUDE; "face value (9.4 MJup) excluded" if all five are at least WEAK-EXCLUDE; otherwise INCONCLUSIVE (report per-window S_W, a_W, M95). Windows may be dropped as inactive only on the basis of published, citable transit non-detections dated before 2026-12-02 and listed explicitly; the unrestricted five-window result is always also reported. Every deviation from this document is labelled post hoc in the memo.

## 7. Forecast (v2; recorded for later comparison)
Offline tests of the v2 fitter on simulated DR4-format data (per-FoV σ = 0.75 × 41.7 µas, 93 epochs with 10% dropout; 40 seeds each, 100 controls; results/phaseB_tests_v2.md): injected 9.4 MJup companion in W4 — DETECT in any window 75% (W4 itself 70%), vs 67.5% / 60% under v1; no-signal runs — 0/40 false detections, median W4 95% mass limit 3.9 MJup (v1: 3.89). Claim-true with truth drawn from the paper posterior (60 seeds, windows and K random): DETECT ≈ 55% overall (≈ 38–64% by window; small samples). The remaining power cost is the (unchanged) ΔBIC≥10 requirement (S ≥ 19.1) plus the amplitude and phase-consistency conditions: the raw Δχ²>13.82 criterion alone is met in ≈83% of the posterior-truth runs. Claim false: P(strong EXCLUDE, M95<5.3 MJup) ≈ 0.66–0.86 central noise, 0.16–0.44 if DR4 noise equals DR3's, ≥0.98 if 50% better (scripts/sim.py; unchanged by v2 since upper limits use s²≈1 for null data); median M95 ≈ 4 MJup (central). Most likely overall outcome: no detection; strong exclusion or inconclusive depending on DR4 noise. Offline-only numbers: DR4 noise is unknown.
